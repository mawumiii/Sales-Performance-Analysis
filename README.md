Project title

Sales Performance Analysis Using Power BI

Overview

Analyzed sales data to understand sales performance across different dimensions such as state, category, sub-category and time.

Objectives

Analyze overall sales performance
Evaluate profitability
Identify high- and low-performing areas
Compare sales across states
Analyze category and sub-category performance
Examine sales trends over time
Provide insights that can support business decision-making

Tools Used:

Microsoft Power BI
Power Query
DAX
Data Visualization
Data Cleaning
Exploratory Data Analysis
